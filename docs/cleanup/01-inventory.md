## 3. 全体の一覧（調べた範囲）

- **お客様**：`/order/:qrToken/` → 人数 → メニュー → カート → 注文状況・会計依頼。下部ナビはメニュー／カート／履歴・会計。
- **スタッフ**（`/staff/*`）：店舗コード → スタッフ選択＋4桁パス → 席一覧・席詳細・残り・注文追加・精算・キッチン。権限があれば、店舗管理メニューから管理用の7画面を開ける。
- **厨房**：`/staff/kitchen`（権限 `useKitchen`）。提供済み・取消・音の設定。
- **管理**（`/admin/*`）：商品・席・スタッフ・予約・売上・操作ログ・設定の7タブ（＋タブに無いカテゴリー）。
- **オーナー**（`/owner`）：店舗一覧・店舗名・店舗管理者メール・代理管理・許可メール。
- **スタッフ権限8つ**：キッチン、レジ締め、メニュー管理、席管理、予約管理、履歴閲覧、店舗設定、スタッフ権限管理。どれも画面では使われている。rules で守られていないのはキッチンだけで、Functions はどれも見ていない（K5）。
- **店舗設定**：お客様画面4つ（提供済み表示、商品ごとの金額、追加注文、行タップで追加）、運用3つ（通知、提供済み管理、人数分の自動追加）、税率。どれも実際に読まれている。
- **使われていないファイル**：見つからなかった（すべてどこかから import されている）。

## 4. 次の進め方（案）

2. 2章の候補を「残す／まとめる／消す」に仕分ける。
3. 仕分けた結果を章に分け、1章ずつ kakunin → 試作 → 本番で進める。権限・rules（K5〜K7、L1）は注文の流れに関わるので、同時注文の確認を必ず通す。
